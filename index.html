TECH TEEN LAUNCHPAD

My Journey
Into Technology

From starting with zero coding experience to building websites, learning new tools, and creating real-world projects.

When I first started Tech Teen Launchpad, I had no background in coding. HTML, CSS, Python, and GitHub were all completely new to me.

Throughout the program, I learned the fundamentals of programming and web development. I learned how HTML creates structure, how CSS brings a website to life, and how Python can be used for logic and problem-solving.

Through hands-on activities, Codedex, presentations, and projects, I became more comfortable experimenting with code, debugging, and trying again when something did not work.

One of the biggest parts of my journey was helping build the Local Skill Emergency Hotline. This project allowed me to apply what I learned to something designed to help a community.

WHAT I LEARNED

Skills & Tools I Developed

Throughout Tech Teen Launchpad, I was introduced to programming languages and tools used to design, build, organize, and share digital projects.

HTML

I learned how HTML provides the structure of a webpage. I practiced using headings, paragraphs, links, images, buttons, and sections to organize content.

CSS

I learned how CSS can transform a basic webpage through colors, fonts, spacing, layouts, borders, and other design elements.

Python

Python introduced me to programming logic and problem-solving. I also learned how debugging is an important part of coding.

Figma

I learned how Figma can be used to plan and visualize digital designs before turning an idea into a functional project.

VS Code

VS Code became one of the main tools I used to write and organize my code. It helped me become more comfortable working with HTML and CSS files.

GitHub

I learned how GitHub can be used to store, manage, and share projects. I also became familiar with repositories and publishing work online.

Canva

Canva has been an important part of my creative work. I use it for presentations and visual materials, including projects for my nonprofit, MedYouCare. I plan to continue using Canva as I develop more projects.

MY PROGRESS

My Technical Learning Journey

I started Tech Teen Launchpad with no coding experience, so everything from HTML and CSS to Python was new to me.

As I practiced, I became more comfortable writing code, fixing mistakes, and creating webpages on my own.

Building the Local Skill Emergency Hotline was one of the biggest parts of my growth because I was able to apply what I learned to a real project.

I still have a lot to learn, but I now feel much more confident exploring technology and creating things on my own.
