TECH TEEN LAUNCHPAD

My Journey
Into Technology

From starting with zero coding experience to building websites, learning new tools, and creating real-world projects.

When I first started Tech Teen Launchpad, I had absolutely no background in coding. I had never built a website from scratch, and concepts like HTML, CSS, Python, and GitHub were completely new to me.

Throughout the program, I began learning the fundamentals of programming and web development. I learned how HTML creates the structure of a webpage, how CSS can transform that structure into a visually appealing website, and how Python can be used for programming logic and problem-solving.

What started as something completely unfamiliar gradually became something I could actually understand and create with. Through hands-on activities, Codex, presentations, and projects, I became more comfortable experimenting with code, making mistakes, debugging, and trying again.

One of the biggest parts of my journey was helping build the Local Skill Emergency Hotline. This project allowed me to take the skills I developed throughout the program and apply them to a larger project that could actually be used by a community.

This portfolio documents my journey — from having zero coding experience to becoming more confident with technology, creating projects, and discovering new interests along the way.

WHAT I LEARNED

Skills & Tools I Developed

Throughout Tech Teen Launchpad, I was introduced to both programming languages and the tools used to design, build, organize, and share digital projects. Since I started with no previous coding experience, learning these technologies helped me develop a foundation in both technical and creative skills.

The skills that stood out to me the most were HTML, CSS, and Python. I also became familiar with tools such as Figma, VS Code, GitHub, and Canva. Each tool helped me approach technology from a different perspective, whether that meant writing code, designing an idea, organizing a project, or sharing my work.

HTML

I learned how HTML provides the structure of a webpage. I practiced using elements such as headings, paragraphs, links, images, buttons, and sections to organize content and create the foundation of a website.

CSS

I learned how CSS can transform a basic HTML webpage into something visually appealing. I practiced styling colors, fonts, spacing, layouts, borders, and other design elements. CSS became one of my favorite parts because it allowed me to give my websites their own personality.

Python

Python introduced me to the programming side of technology. I learned how to think logically, work through problems, and use code to create solutions. Debugging also taught me that mistakes are an important part of learning how to code.

Figma

I learned how Figma can be used to plan and visualize digital designs before building them. It helped me think about layout, organization, and the overall appearance of a website or digital project before turning an idea into something functional.

VS Code

VS Code became one of the main tools I used to write and organize my code. Working in a real code editor helped me become more comfortable navigating files, editing HTML and CSS, fixing mistakes, and seeing how different files work together to create a website.

GitHub

I learned how GitHub can be used to store, manage, and share projects. I became more familiar with repositories, committing changes, and publishing my work online. GitHub also helped me understand how developers organize and keep track of their projects.

Canva

Canva has been an important part of my creative and technical learning. I have used Canva to create presentations, organize ideas, and make projects more visually engaging. I also use Canva for my nonprofit, MedYouCare, where I create and organize visual materials. I plan to continue using Canva for MedYouCare as I develop more projects and continue improving my design skills.

MY PROGRESS

My Technical Learning Journey

My technical journey started with zero coding experience. Before Tech Teen Launchpad, I had never built a website or worked with programming languages. I was unfamiliar with concepts like HTML, CSS, Python, repositories, and code editors.

At first, learning how to code felt challenging because there were so many new concepts and terms to understand. I had to learn how different files worked together, how to find mistakes in my code, and how to keep trying when something did not work the first time.

As I progressed through the program, I became more comfortable experimenting with code. I started to understand how HTML creates structure, how CSS changes the appearance of a webpage, and how Python can be used for programming and problem-solving.

One of the biggest changes I noticed was my confidence. I went from having zero coding experience to being able to create and edit my own webpages. I learned that struggling with code does not mean I cannot do it. Sometimes it simply means I need to slow down, figure out the problem, and try again.

This experience also helped me become more interested in web development and digital creation. I want to continue practicing the skills I learned instead of stopping after the program ends.
