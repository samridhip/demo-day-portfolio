TECH TEEN LAUNCHPAD

My Journey
Into Technology

From starting with zero coding experience to building websites and real-world projects.

When I first started Tech Teen Launchpad, I had absolutely no background in coding. I had never built a website from scratch, and concepts like HTML, CSS, Python, and GitHub were completely new to me.

Throughout the program, I began learning the fundamentals of programming and web development. I learned how HTML creates the structure of a webpage, how CSS can transform that structure into a visually appealing website, and how Python can be used for programming logic and problem-solving.

What started as something completely unfamiliar gradually became something I could actually understand and create with. Through hands-on activities, Codex, presentations, and projects, I became more comfortable experimenting with code, making mistakes, debugging, and trying again.

One of the biggest parts of my journey was helping build the Local Skill Emergency Hotline. This project allowed me to take the skills I developed throughout the program and apply them to a larger project that could actually be used by a community.

This portfolio documents that journey — from my first experiences with coding to the projects I created and the goals I discovered along the way.

WHAT I LEARNED

Skills & Tools I Developed

Throughout Tech Teen Launchpad, I was introduced to both programming languages and the tools used to design, build, and share digital projects. I started with no previous coding experience, so learning these technologies helped me develop a foundation in both technical and creative skills.

The skills that stood out to me the most were HTML, CSS, and Python. I also became familiar with tools such as Figma, VS Code, and GitHub. I plan to continue developing my skills through Canvas and other learning resources as I continue exploring technology.

HTML

I learned how HTML provides the structure of a webpage. I practiced using elements such as headings, paragraphs, links, images, buttons, and sections to organize content and create the foundation of a website.

CSS

I learned how CSS can transform a basic HTML webpage into something visually appealing. I practiced styling colors, fonts, spacing, layouts, borders, and other design elements.

Python

Python introduced me to the programming side of technology. I learned how to think logically, work through problems, and use code to create solutions. Debugging also taught me that mistakes are an important part of learning how to code.

Figma

I learned how Figma can be used to plan and visualize digital designs before building them. It helped me think about layout, organization, and the overall appearance of a website or digital project.

VS Code

VS Code became one of the tools I used to write and organize my code. Working in a real code editor helped me become more comfortable navigating files, editing HTML and CSS, and seeing how different files work together to create a website.

GitHub

I learned how GitHub can be used to store, manage, and share projects. I became more familiar with repositories and using GitHub to keep track of and publish my work online.

Canvas

Canvas has also been a part of my continued learning experience. I use it to access learning materials, assignments, and resources that help me continue practicing and developing my technical skills.
