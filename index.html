TECH TEEN LAUNCHPAD

My Journey
Into Technology

From starting with zero coding experience to building websites, learning new tools, and creating projects with a purpose.

When I first started Tech Teen Launchpad, I had zero background in coding. I had never built a website from scratch, and concepts like HTML, CSS, Python, and GitHub were completely new to me.

The beginning of the program was about learning the basics and understanding how technology works. I learned how HTML creates the structure of a webpage, how CSS changes its appearance, and how Python can be used to solve problems through code.

As I practiced, I became more comfortable working with code and using tools like VS Code and GitHub. I learned that coding is not about getting everything right immediately. Debugging, making mistakes, and trying different solutions became an important part of how I learned.

My experience eventually led me to work on the Local Skill Emergency Hotline, a community-focused project where I could apply the skills I had developed. Being able to take an idea, plan its structure, and turn it into a working website showed me how much I had progressed.

This portfolio shows that progression, from my first experiences with coding to the projects I created, the tools I explored, and the goals I discovered along the way.

WHAT I LEARNED

Skills & Tools I Developed

Throughout Tech Teen Launchpad, I was introduced to programming languages, design tools, and platforms used to create and share digital projects. Since I started with no previous coding experience, each new technology gave me another way to understand how digital projects are created.

HTML, CSS, and Python stood out to me the most because they helped me understand both the structure of websites and the logic behind programming. I also became familiar with Figma, VS Code, GitHub, and Canva, which helped me approach projects from both technical and creative perspectives.

HTML

I learned how HTML provides the structure of a webpage. I practiced using headings, paragraphs, links, images, buttons, and sections to organize content and create the foundation of a website.

CSS

I learned how CSS can transform a basic HTML webpage into something visually engaging. I practiced working with colors, fonts, spacing, layouts, borders, buttons, and other design elements. CSS showed me how coding can also be a creative process.

Python

Python introduced me to the programming side of technology. I learned how to approach problems logically, work with code, and think through different solutions. Debugging helped me become more patient when something did not work the first time.

Figma

I learned how Figma can be used to plan and visualize digital designs before building them. It helped me think about layouts, organization, user experience, and how a website could look before turning an idea into something functional.

VS Code

VS Code became one of the main tools I used to write and organize my code. Working in a real code editor helped me become more comfortable navigating files, editing HTML and CSS, and understanding how different files work together.

GitHub

I learned how GitHub can be used to store, manage, and share projects. I became more familiar with repositories, commits, branches, and publishing projects online. GitHub also gave me a place to keep track of the work I created.

Canva

Canva has been an important part of my creative work. I use Canva to create presentations, organize ideas, and make visual materials more engaging. I also use Canva for my nonprofit, MedYouCare, where I create and organize visual materials. I plan to continue using Canva for MedYouCare as I develop more projects and strengthen my design skills.

MY PROGRESS

My Technical Learning Journey

My technical journey started with zero coding experience. Before Tech Teen Launchpad, I had never built a website or worked with a programming language. Even basic concepts such as HTML tags, CSS properties, repositories, and code editors were unfamiliar to me.

At first, there was a lot to learn at once. I had to understand how different files connected, how to recognize errors, and how to figure out why something was not displaying the way I expected. Instead of seeing mistakes as failures, I gradually learned to treat them as part of the process.

As I continued practicing, I became more comfortable experimenting with code. I started understanding how HTML creates structure, how CSS controls the design of a webpage, and how Python can be used to approach problems logically.

My biggest growth has been in confidence. I went from not knowing how websites were created to being able to write, edit, style, and organize my own webpages. I am now much more willing to try something new, research a problem, and figure out a solution when my code does not work immediately.

This experience also helped me discover a stronger interest in web development and digital creation. I want to keep practicing instead of treating the end of the program as the end of my learning.
