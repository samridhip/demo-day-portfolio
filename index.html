TECH TEEN LAUNCHPAD

My Journey
Into Technology

From starting with zero coding experience to building websites, learning new tools, and creating real-world projects.

When I first started Tech Teen Launchpad, I had no background in coding. HTML, CSS, Python, and GitHub were all completely new to me.

Throughout the program, I learned the fundamentals of programming and web development. I learned how HTML creates structure, how CSS brings a website to life, and how Python can be used for logic and problem-solving.

Through hands-on activities, Codedex, presentations, and projects, I became more comfortable experimenting with code, debugging, and trying again when something did not work.

One of the biggest parts of my journey was helping build the Local Skill Emergency Hotline. This project allowed me to apply what I learned to something designed to help a community.

WHAT STOOD OUT TO ME

Topics & Tools I Learned

The topics that stood out to me most were HTML, CSS, and Python because they introduced me to different sides of technology. I also learned how tools such as Figma, VS Code, GitHub, and Canva can support the development process.

HTML

HTML stood out to me because it showed me how websites are structured. I learned how headings, paragraphs, links, images, buttons, and sections work together to create a webpage.

CSS

CSS became one of my favorite topics because I could see an immediate difference when I changed colors, fonts, spacing, layouts, and other design elements.

Python

Python introduced me to programming logic and problem-solving. It taught me to break problems into smaller steps and understand that debugging is part of learning.

Figma

I learned how Figma can be used to plan and visualize digital designs before building them. It helped me think about layout, organization, and the appearance of a digital project.

VS Code

VS Code helped me become comfortable writing and organizing code and understanding how different files work together.

GitHub

GitHub taught me how projects can be stored, organized, managed, and shared online through repositories.

Canva

I use Canva to create presentations and visual materials, including projects for my nonprofit, MedYouCare. I plan to continue using it for future projects.
